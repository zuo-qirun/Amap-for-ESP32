# AMap ESP32 Lyrics for BetterNCM

网易云音乐桌面端的歌词副屏插件。它通过 BetterNCM 的 `LibLyric` 获取逐行原文和翻译，并以与手机端相同的 v1 `music_update` JSON 协议，经 UDP 发给 ESP32。

## 安装与配置

1. 在 BetterNCM 插件市场安装并启用 `LibLyric`。
2. 导入本插件后重启网易云音乐。
3. 打开本插件设置，填写 **ESP32 的局域网 IPv4 地址**；没有默认 IP。UDP 端口默认 `4210`。
4. 电脑与 ESP32 需要在同一局域网，或电脑直接连到 ESP32 配网热点。

BetterNCM 的浏览器插件环境本身不能创建 UDP socket，因此插件会自动启动包内的本机 UDP 助手。控制接口仅供本机插件使用；音乐帧以 UDP v1 发往你在设置中填写的 ESP32 地址，ESP32 的播放控制则通过同一 UDP socket 返回。

换歌、歌词换行、播放/暂停时会立即发送；播放期间每秒补发一次时间基准，ESP32 会在更新之间自行插值。

## 0.2.7

- ESP32 播放页的上一首、播放/暂停、下一首按钮可直接控制电脑端网易云音乐。
- UDP 助手改为复用同一个双向 socket，避免 ESP32 回复到已经关闭的临时端口。
- ESP32 只把控制命令发回当前实际拥有音乐状态的传输来源，避免 BLE 空媒体心跳抢走 BetterNCM 的控制通道。

## 0.2.6

- 歌词加载期间保持同一个播放页面，不再在“暂无歌词”和播放页之间反复跳转。
- 为异步歌词和封面请求增加歌曲代次校验，上一首歌的慢响应不会覆盖当前歌曲。
- 没有歌词时发送稳定的“暂无歌词”状态，加载中则显示“歌词加载中”。
